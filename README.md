# RemiX LinguaStep — Personal Adaptive English Tutor

LinguaStep is an AI-powered, personal English learning application delivering adaptive daily practice, placement exams, instant feedback, interactive AI tutor explanations, and multi-day learning roadmaps.

## 🚀 Key Features

- **Adaptive Diagnostic Exam**: Multi-section placement assessment with dynamic CEFR level adjustment (A2–C1).
- **Daily Tailored Sessions**: 10, 20, or 30-minute structured daily lessons with zero-delay pre-generated questions.
- **Dual-Language Explanations**: Native explanations in English or Vietnamese (`vi`).
- **Interactive AI Tutor**: In-depth hints, simplified explanations, and contextual deep-dive Q&A.
- **Curriculum Roadmap**: Visualized multi-day progress and skill mastery trajectory.

## 📄 Project Steering & Knowledge Guidelines

For developer guidelines, architecture, prompting rules, and file organization standards, see [STEERING.md](./STEERING.md).

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Type checking
npx tsc --noEmit

# Build production application
npm run build
```
